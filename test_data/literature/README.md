# Literature fixtures

Values published by other people, recorded so the acceptance suite can try to
reproduce them. These validate the definitions: disagreement means this project
is wrong, not the source ([`../../docs/trusted-base.md`](../../docs/trusted-base.md)).

## Provenance warning

**Every value here is second-hand.** Each was transcribed from a secondary
account — named in that file's `transcribed_from` field — which attributes it to
a primary source this project has not yet obtained. See
[`../../references/README.md`](../../references/README.md), where all of them
are still `sought`.

So a mismatch has three possible causes, not two: the definitions are wrong,
the source is wrong, or the transcription is wrong. Check the primary source
before concluding anything from a failure, and set `verified_against_primary`
to the citation once you have.

Ledger rows citing these carry the same caveat.
